# Introducción

El presente trabajo aborda el diseño, la implementación y la validación técnica de una solución en Python orientada al almacenamiento y gestión de datos en memoria mediante listas y diccionarios.

El desarrollo se articula en tres componentes clave:

1. **Diagrama esquematico:** Diagrama que modela la trayectoria de la información desde la interacción del usuario hasta su estructuración en memoria.
2. **Código Fuente en Python:** Implementación funcional en script `.py`, comentada y estructurada bajo buenas prácticas de programación.
3. **Sustentación Oral:** Explicación y trazabilidad directa entre la lógica del código y los bloques conceptuales del diagrama.
